The Sui jars include open-source and third-party libraries, each under its own license. Their license and
notice files are kept inside the jar under `META-INF/`. The main ones are:

| Library | Used for | License | In jar |
|---|---|---|---|
| [FlatLaf](https://www.formdev.com/flatlaf/) | Look and feel (light and dark themes) | Apache 2.0 | full, minimal |
| [RSyntaxTextArea](https://github.com/bobbylight/RSyntaxTextArea) | SQL editor | BSD 3-Clause | full, minimal |
| [JSqlParser](https://github.com/JSQLParser/JSqlParser) | SQL parsing and formatting | Apache 2.0 / LGPL 2.1 | full, minimal |

| IBM Data Server Driver for JDBC (`db2jcc`) | Db2 connections | IBM license terms | full |
| [Google BigQuery JDBC driver](https://github.com/googleapis/java-bigquery) and Google Cloud client libraries (gRPC, Netty, Protocol Buffers, OpenTelemetry and others) | BigQuery connections | Apache 2.0 and BSD-style | full |
